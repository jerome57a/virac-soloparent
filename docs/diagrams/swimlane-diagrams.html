e-SoloParentID: Swimlane Diagrams

An Online Application and Renewal System with Automated Verification and SMS Notification

Diagram 1: New Solo Parent ID Application

This shows what happens from the day a Solo Parent registers until the ID is handed over.

  • There are three actors: the Solo Parent, the System (automatic checks and SMS texts) and the MSWDO Staff.
  • Read from top to bottom and follow the arrows. An arrow that moves to another column is a handoff.
  • Dashed arrows are text messages (SMS). The System sends them. Only the steps that need the Solo Parent are texted.
  • Diamonds are questions. Follow "Yes" or "No".

Diagram 2: Renewal of the Solo Parent ID

Renewal follows the same path as a new application, with these differences:

  • Renewal opens on the day the ID expires and stays open for 365 days. After that the Solo Parent applies again as a new application.
  • Only the documents with no accepted, unexpired copy on file are asked, not the full list for a new application. A child over 22 with a disability needs a PWD ID or medical certificate.
  • The interview is a re-check (RA 11861). The Solo Parent must show the current Solo Parent ID.

Diagram 3: Side Flows

Three smaller flows that happen beside the main ones. Each one is short and has its own diagram.

  • 3A: the Solo Parent did not come to the interview.
  • 3B: the interview date passed and staff never recorded what happened.
  • 3C: the automatic text sent when the ID expires.

3A. The Solo Parent missed the interview

Staff mark a no-show only after the date has passed. No text is ever sent for a missed interview: the Solo Parent sees a notice in the account.

3B. Nobody recorded the interview result

If staff do not record Attended or Did not attend within 2 weekdays, the system reopens the booking by itself.

3C. The ID-expiry text

One text is sent on the exact expiration date that staff typed from the card.
