System Architecture

e-SoloParentID: how the parts of the system fit together

How to read it

  • Read from top to bottom. An arrow means "calls" or "sends data to". The browser and the application send pages and requests both ways.
  • The Solo Parent, MSWDO Staff and MSWDO Admin all use the same web browser and the same PHP application. What each one sees depends on the role.
  • The services hold the rules. Only they call the SMS gateway and Tesseract. The scheduled jobs also run through the services.
  • The MySQL database keeps the records. It is the MySQL module of XAMPP (its engine is MariaDB 10.4). A separate test database is used only for testing and is not drawn. The file storage keeps the uploaded documents, and a document can only be opened through download.php.
  • Simple pages may read the models directly, without going through a service. This is not drawn, to keep the picture simple.
